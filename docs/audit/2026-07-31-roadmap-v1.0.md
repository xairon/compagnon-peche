# Roadmap v1.0 — lots, propriété des fichiers, vagues

Base : `docs/audit/2026-07-31-plan-execution.md` section v1.0, plus les fils laissés ouverts
par la session du 31/07/2026 (voir `REPRISE.md`).

## Contrat commun à tous les lots

Non négociable, c'est la méthode du dépôt :

1. **TDD strict.** Le test rouge d'abord, et il doit échouer **pour la bonne raison** (pas un
   import manquant qu'on n'a pas regardé). Vérifier le rouge, puis le vert.
2. **Vérifier sur les données réelles avant d'écrire une ligne.** Sept API publiques : à chaque
   fois qu'on a supposé ce qu'un champ voulait dire, on s'est trompé. `curl --ssl-no-revoke`
   sous Windows.
3. **Ne jamais faire dire à une source ce qu'elle ne dit pas.** Trois états — oui / non /
   inconnu — partout où la source en a trois. Un champ vide n'est pas un « non ».
4. **Commits en français**, sujet court, corps qui explique le *pourquoi* avec les chiffres
   mesurés, et qui **dit ce qui n'a pas été vérifié**.
5. `npx eslint src`, `npm test`, `npm run build` doivent passer avant chaque commit.

## Propriété des fichiers

Un lot ne touche **que** ses fichiers. C'est ce qui rend les vagues parallélisables.
`src/styles.css` est partagé : **ajouter en fin de fichier**, ne jamais réécrire l'existant.

## Vague 1 — parallèle, fichiers disjoints

### Lot A · Réveiller le critère du cours d'eau
`src/lib/geo.ts` · `src/lib/cours-du-point.ts` · `src/lib/hubeau.ts` · `src/components/Briefing.tsx`

Le critère est complet et testé (`choisirStation(…, coursRef)`) mais **dormant** : personne ne
fournit `coursRef`. Il faut :
- une distance point-vers-polyligne dans `geo.ts` (pure, testée) ;
- `coursDuPoint()` qui accepte un point et ne retient que les tronçons à moins de N mètres,
  au lieu d'exiger que la zone entière ne contienne qu'un cours d'eau ;
- joindre `qualite_rivieres/station_pc` par `code_station` pour donner un cours d'eau aux
  analyses physico-chimiques, qui n'en portent aucun ;
- brancher le tout dans le briefing.

**Fini quand** : depuis Blois, `waterTemp` retient LOIRE à MUIDES-SUR-LOIRE (17,2 km) au lieu
de ne rien retenir.
